# FHS — HTML-прототип записи

Откройте `index.html` в браузере или раздавайте папку репозитория любым статическим хостингом. Сборка и установка зависимостей не нужны. Все файлы приложения находятся в корне репозитория; изображение интерьера и логотип включены локально. При недоступности Google Fonts используются системные шрифты.

Работает выбор нескольких услуг, категорий, мастера, даты и времени; пересчёт цены и длительности; проверка контактных данных; подтверждение; список записей; перенос; отмена; экспорт в календарь. Даты начинаются с текущего дня в часовом поясе Минска. Демо-записи хранятся в localStorage конкретного браузера, без сервера. Они не являются реальным бронированием.

Основа сценария: официальная документация YCLIENTS https://support.yclients.ru/178--shagi-individualnoj-onlajn-zapisi и https://support.yclients.ru/32-34-174--ssylka-vidzhet-i-forma-dlya-onlajn-zapisi/. Прототип самостоятельно реализует механику; интеграции с YCLIENTS нет.

Для Telegram Mini App: раздать файлы сайта по HTTPS, привязать URL к кнопке бота через BotFather; добавить официальный Telegram WebApp SDK для интерфейса и серверную проверку initData для авторизации. Затем заменить демо-данные услуг, мастеров и слотов вызовами собственного сервера / YCLIENTS, реализовать атомарное бронирование на сервере и подтверждения. Секреты YCLIENTS и Telegram нельзя хранить во фронтенде. Данные профиля из Telegram считать доверенными только после серверной проверки подписи.

Требует уточнения: адрес и город, действительный прайс, мастера, расписание, контакты и тексты согласий. Изображение интерьера: Unsplash, иллюстративное, не фотография FHS. Логотип предоставлен заказчиком.
